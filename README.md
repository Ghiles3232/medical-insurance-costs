# U.S. Medical Insurance Costs

A data science project that analyzes medical insurance charges. Uses age, BMI, smoking, region, and other factors to explore and predict costs.

## What you need

- Python 3.8+
- Jupyter (to run the notebook)

## Install

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Or run the first cell in the notebook—it installs the packages for you.

## How it works

1. Open `us-medical-insurance-costs.ipynb` in Jupyter.
2. Run the first cell (install) if needed, then restart the kernel.
3. Run all cells. The notebook walks through:
   - Loading and checking the data
   - Plots and stats
   - Building models to predict charges
   - Comparing models and checking results

The data is in `insurance.csv`. Keep it in the same folder as the notebook.
